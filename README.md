# zesty-isle-tool

gRPC · Compilers · CUDA

处理日常小任务的工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/zesty-isle-tool.git
cd zesty-isle-tool
chmod +x run.sh
```
